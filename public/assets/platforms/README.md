## shops/ (Official Shop section on the Products page)

Full-color official app icons, resized locally, used so the "Official Shop" cards look like the real marketplace badges instead of flat silhouettes:

- `tokopedia.png`: Tokopedia's own PWA icon, served from its public `manifest.json` (`icons` field) on tokopedia.com.
- `tiktok-shop.webp`: the "TikTok Shop Seller Center" app icon, sourced via Apple's public iTunes Lookup/Search API (`itunes.apple.com/search`).

Shopee keeps using the Simple Icons glyph above (`shopee.svg`, inverted to white on an orange badge) — the icon shipped in Shopee's own manifest had a corrupted alpha channel on its "S" mark and was unusable.

Brand names and logos belong to their respective owners.
